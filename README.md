# UT ECE Course Explorer

What every undergraduate UT Austin Electrical and Computer Engineering (ECE) course actually teaches, built from public syllabi, the UT catalog and the Registrar schedule.

- `pipeline/` Python data pipeline (course list, sections, syllabi, topic analysis, export). The raw data (`/data`) stays local.
- `site/` Astro static site; its data ships in `site/src/data`.

Unofficial student project, not affiliated with The University of Texas at Austin.
